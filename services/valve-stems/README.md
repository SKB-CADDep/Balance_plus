Бэкенд микросервиса для автоматизированного термодинамического и гидравлического расчёта штоков клапанов турбин в экосистеме **Balance+ IDE**.

## 📖 Описание проекта

Данный сервис отвечает за расчет параметров пара и воздуха для участков клапана. Он выполняет поиск чертежей по названию турбины в базе данных, анализирует геометрию и проводит комплексные вычисления (расходы пара, отсосы в деаэратор и эжектор уплотнений).

> **[ENGINEERING CONTEXT] Эволюция архитектуры:**
> Ранее проект представлял собой монолитное консольное приложение (`InputFromUser.py`, сырой `psycopg2`). В текущей мажорной версии математическое ядро (алгоритмы `StockRazchetsKlapans`, `WSAProperties`) было бережно перенесено и обернуто в современный асинхронный REST API на базе **FastAPI** и **SQLAlchemy**. Ввод данных теперь осуществляется через веб-интерфейс, а расчеты делегируются в фоновые задачи (Celery).

## 🧮 Функциональность API

- Поиск и выдача метаданных чертежей клапанов по ID или названию турбины.
- Асинхронный расчёт параметров пара и воздуха для каждого участка клапана.
- Поддержка различных типов турбин и переменного количества участков.
- Автоматизированный подсчёт расходов пара для клапанов и воздуха с использованием международного стандарта IAPWS-IF97.

> **[ENGINEERING CONTEXT] Почему используется `seuif97`:**
> Библиотека `seuif97` реализует стандарт IAPWS-IF97 для расчета свойств воды и водяного пара. Самописная реализация этих формул несла бы огромные риски погрешностей. Использование сертифицированной C-библиотеки с Python-оберткой гарантирует скорость вычислений и промышленную точность, необходимую для турбостроения.

## 🏗 Структура проекта (Современная)

* `api/routes/` — HTTP-контроллеры, заменившие устаревший `InputFromUser.py`.
* `core/math/` — Изолированное математическое ядро (свойства воздуха, коэффициенты сопротивления).
* `db/` — ORM-модели SQLAlchemy для работы с таблицами турбин и чертежей (замена старым SQL-строкам).
* `schemas/` — Pydantic-модели для строгой валидации входящих JSON-данных.

Создайте файл `.env` в корне директории бэкенда.
