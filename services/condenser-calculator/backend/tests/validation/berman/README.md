# 📑 README: Система верификации расчетов конденсаторов по методу Бермана

Данный комплекс скриптов предназначен для контроля точности физико-математического движка конденсаторов при работе с реальными промышленными объектами (на примере конденсаторов **К-3100-XIII**, **КГ2-6200-III** и **КГ2-7300-Iм**).

```
[ PDF / Excel Отчеты ] 
       │ (ручной перенос базовых параметров)
       ▼
[ geometry_*.json ] ──► [ save_results.py ] ──► [ results_*.json (Эталоны) ]
[   mode_*.json   ]           │                              ▲
                              ▼                              │ (сравнение)
                    [ BermanStrategy.py ] ◄──────────────────┤
                              ▲                              │
                              │ (вызов расчетов)             │
                ┌─────────────┴─────────────┐                │
                │                           │                │
     [ validate_condenser_math.py ]    [ test_berman_verification_calc.py ]
     (Быстрая консольная отладка)       (Автоматический запуск в pytest)
```

---

## 1. Скрипт `save_results.py` (Генератор математических эталонов)

* **Расположение:** `tests/validation/berman/save_results.py`
* **Для чего нужен:** Автоматическое формирование эталонных данных (Baselines) без ручного кодинга.
* **Какую функцию выполняет:**
  1. Находит и загружает входные файлы геометрии (`geometry_*.json`) и режимов работы (`mode_*.json`) для трех верифицируемых конденсаторов.
  2. Передает их в адаптивный маппер обертки и запускает оригинальный расчет `BermanStrategy.calculate()`.
  3. Собирает плоский массив результатов расчетов, автоматически группирует его в сложные двухмерные матрицы давлений (по осям температур $t1$ и расходов пара $G_{steam}$) для всех возможных комбинаций расходов воды ($W$) и загрязнений ($b$).
  4. Формирует и записывает три структурированных эталонных файла: `results_k3100.json`, `results_kg2_6200.json` и `results_kg2_7300.json` в папку `results/`.
* **Когда запускать:** Запускается **один раз** при добавлении новых типов конденсаторов или при контролируемом, согласованном изменении математической модели (для перезаписи эталонов).

## 2. Тест `test_berman_verification_calc.py` (Автоматический тест-валидатор)

* **Расположение:** `tests/validation/berman/test_berman_verification_calc.py`
* **Для чего нужен:** Интеграция математических проверок в общий тестовый раннер (`test_runner.py` / `pytest`) для предотвращения регрессионных ошибок при сборке проекта в CI/CD (GitLab/GitHub).
* **Какую функцию выполняет:**
  1. Выступает точкой входа для кастомного плагина тестирования математики (благодаря суффиксу `_calc.py` в имени файла и переменным `target_function` и `tests`).
  2. Выполняет роль **адаптера-переводчика**: сопоставляет современные древовидные веб-структуры JSON (Pydantic-схемы) с плоскими именами переменных, которые исторически жестко зашиты внутри физического ядра `BermanStrategy` (ключи `L_main`, `S_tube`, `d_in`, `G_nom`, `lambda` и т.д.).
  3. Передает преобразованный плоский словарь в расчетное ядро.
  4. Сравнивает полученные матрицы давлений с эталонными файлами из папки `results/` с плавающей точностью до $10^{-6}$ (6-й знак после запятой).
* **Когда запускать:** Запускается **автоматически** при каждом запуске `pytest` или через `test_runner.py` при сборке коммитов.

## 3. Скрипт `validate_condenser_math.py` (Автономный консольный отладчик)

* **Расположение:** `tests/validation/berman/validate_condenser_math.py`
* **Для чего нужен:** Быстрый ручной анализ и поиск математических расхождений инженерами-расчетчиками без необходимости запускать тяжелую среду тестирования `pytest`.
* **Какую функцию выполняет:**
  1. Позволяет выполнить расчеты «в один клик» напрямую из консоли Python.
  2. Сравнивает текущие расчетные данные с эталонными и выводит в терминал детальный человекочитаемый лог.
  3. В случае расхождений показывает точные координаты отклонений: индекс строки ($t1$), индекс столбца ($G_{steam}$), конкретное расчетное и эталонное значение, а также дельту ошибки.
* **Когда запускать:** Запускается **вручную инженером** во время отладки формул, когда вносятся изменения в алгоритмы теплопередачи или теплообмена, чтобы сразу локализовать, на каких температурных режимах или расходах «поплыла» математика.
