# Condenser Calculator — Frontend

Frontend-приложение для расчёта тепловых и гидравлических характеристик паровых конденсаторов (Balance_plus).

## 🛠 Стек технологий

- **Фреймворк:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Роутинг:** [@tanstack/react-router](https://tanstack.com/router)
- **Управление состоянием и API:** [@tanstack/react-query](https://tanstack.com/query)
- **UI-библиотека:** [Chakra UI](https://chakra-ui.com/)
- **Формы:** [React Hook Form](https://react-hook-form.com/)
- **Генерация API-клиента:** OpenAPI / Swagger (клиент находится в `src/client/`)

## 📂 Структура проекта

```text
src/
├── client/                     # Автосгенерированный API-клиент
├── components/
│   ├── Common/                 # Общие переиспользуемые UI-компоненты
│   └── CondenserCalculator/    # Специфичные для калькулятора компоненты
│       ├── CondenserForm.tsx      # Основная форма ввода данных
│       ├── ResultMatrixViewer.tsx # Таблицы с матрицами результатов расчета
│       └── types.ts               # Типизация локальной формы
├── routes/                     # Страницы приложения (TanStack Router)
│   └── calculator.tsx          # Главная страница калькулятора
└── main.tsx                    # Точка входа приложения
```

## 🚀 Запуск и разработка

### 1. Установка зависимостей
Убедитесь, что установлен Node.js, затем выполните:
```bash
npm install
```

### 2. Запуск локального сервера
```bash
npm run dev
```

### 3. Сборка для продакшена
```bash
npm run build
```

## 🧠 Ключевые архитектурные решения

### 1. Взаимодействие с API
В папке `src/client/` находится HTTP-клиент, сгенерированный на основе OpenAPI схемы бэкенда.
- **Чтение данных (GET):** Выполняется через хук `useQuery` из React Query, что обеспечивает кэширование и предотвращает лишние запросы (например, загрузка материалов трубок или самого конденсатора).
- **Мутации (POST/PUT):** Запросы на вычисление выполняются через `useMutation` (см. хук `useCondenserCalculation`).

### 2. Работа с формами и диапазонами (React Hook Form)
Отличительная особенность калькулятора — необходимость принимать как единичные числа, так и диапазоны для генерации матриц (например, `"10-50-5"` или списки через пробел).
- На уровне состояния React Hook Form все числовые поля имеют тип `string`. 
- Компонент `InputWithUnit` объединяет поле ввода и селектор единиц измерения. Он интегрируется с `Controller`, чтобы правильно прокидывать события, `ref`, состояния фокуса (`onBlur`) и `isDisabled` в Chakra UI.
- Финальный парсинг данных для отправки на бэкенд в формате `string | Array<number>` производится в `calculator.tsx` непосредственно перед вызовом API.

### 3. Бизнес-логика методик расчёта
Поведение полей ввода динамически меняется в зависимости от выбранной методики:
- **Берман:** Используется энтальпия пара (`H_steam`), рассчитываются параметры эжекторов (`Z_ejectors`) и поддерживаются встроенные пучки (`W_builtin`, `Z_builtin`). Степень сухости пара блокируется.
- **Метро-Виккерс:** Метод работает со степенью сухости пара (`X_steam`). Энтальпия пара, а также параметры встроенного пучка полностью скрываются из расчётов, блокируются в UI и **не передаются** в payload.
- *Синхронизация температур (BR-04):* Температура на входе во встроенный пучок (`t1_builtin`) автоматически дублирует температуру основного пучка (`t1_main`), пока пользователь не впишет значение вручную.

## 🤝 Рекомендации по доработке
- **Обновление API-клиента:** В случае изменения схемы бэкенда необходимо перегенерировать папку `src/client/` из нового `openapi.json`, чтобы обновить TypeScript-типы.
- **Адаптивная верстка:** Старайтесь не привязываться к жестким значениям ширины. Используйте компоненты `Stack`, `Flex`, и `SimpleGrid`. Группируйте зависимые элементы (например, заголовки и инпуты) в общие контейнеры (`Box` / `Stack`), чтобы при переносе строк на мобильных устройствах верстка не разваливалась.
- **Управление стилями:** Избегайте использования стороннего CSS. Внешний вид должен настраиваться исключительно через пропсы Chakra UI для соблюдения консистентности (поддержка Dark Mode и т.д.).
