# Balance Calculator Service

Микросервис для выполнения итеративных термодинамических расчетов балансов турбин.

## Архитектурные решения
1. **Изоляция математики (Pure Functions):** Логика расчета (DGI, PPI, PSI, PITW) полностью отвязана от GUI (ранее PyQt6). На вход подаются строго типизированные Pydantic-схемы.
2. **Асинхронное выполнение (Celery + Redis):** Так как расчет графа выполняется последовательно (`max_iter` до 50 шагов) и блокирует Event Loop, HTTP-эндпоинты отвечают за валидацию контрактов и постановку задач в очередь.
3. **Shared Core Pattern (Внешние расчеты):** Для устранения сетевых задержек (Latency) внутри цикла решателя, математика смежных сервисов (например, `condenser_math`, `valves_math`) импортируется как локальный Python-пакет. Это предотвращает отправку десятков HTTP-запросов на каждую итерацию сходимости.

## Структура
* `app/api/` — FastAPI роутеры (только валидация OpenAPI и роутинг).
* `app/schemas/` — Pydantic контракты (`CalculationInput`, `CalculationOutput`).
* `app/services/` — Бизнес-логика оркестрации и подготовка данных для графа.
* `app/core_math/` — Чистое математическое ядро (цикл `solver`).
